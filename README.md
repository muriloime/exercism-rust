# exercism-rust

My solutions to the [Exercism](https://exercism.org) Rust track.

Each exercise lives in `rust/<exercise>` with its own `Cargo.toml`, tests, and source. Run an exercise with:

```bash
cd rust/<exercise>
cargo test
```

Submit with:

```bash
exercism submit --track=rust --exercise=<exercise> rust/<exercise>/src/lib.rs
```
